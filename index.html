Notas sobre YouTube y Facebook
  1. El video debe ser público o "no listado" y permitir que se inserte en otros sitios. Si el dueño desactivó esa opción, aparece un error en el reproductor; usa entonces "Abrir original".
  2. En Facebook no se puede cambiar la velocidad de reproducción; en YouTube y en archivos sí.
  3. Esta página debe abrirse desde una dirección web (por ejemplo GitHub Pages). Si la abres con doble clic desde tu computadora, YouTube puede mostrar un error de configuración.
  4. Tus fragmentos se guardan en este navegador, separados por video. Descarga el CSV para conservarlos o compartirlos.
